# 🇯🇵 Japan Pre-Order & Shop System

ระบบสั่งซื้อสินค้าพรีออเดอร์/หิ้วจากญี่ปุ่น พร้อมระบบตะกร้าสินค้า อัปโหลดสลิป จัดการรอบบินญี่ปุ่น และระบบหลังบ้านสำหรับแม่ค้า

---

## ✨ ฟีเจอร์เด่นของระบบ

### 🛍️ ฝั่งลูกค้า (Customer Storefront)
1. **รอบบินญี่ปุ่น (Flight Schedule)**: แสดงรอบบิน วันที่ปิดรับออเดอร์ วันที่บินกลับถึงไทย และวันเริ่มจัดส่งพัสดุ
2. **เลือกซื้อสินค้าและค้นหา**: กรองตามหมวดหมู่ (ขนม, เครื่องสำอาง, วิตามิน, ฟิกเกอร์ ฯลฯ), ค้นหาชื่อสินค้า, กรองเฉพาะสินค้าโปรโมชั่น
3. **ดูรายละเอียดสินค้า & เพิ่มลงตะกร้า**: ปรับจำนวนชิ้น มีป้ายลดราคา/ป้ายโปรโมชั่นชัดเจน
4. **ระบบเข้าสู่ระบบ / สมัครสมาชิก (6 ฟิลด์)**:
   - ชื่อ - นามสกุล (สำหรับจ่าหน้าพัสดุ)
   - Username (สำหรับเข้าสู่ระบบ)
   - รหัสผ่าน (Password)
   - เบอร์โทรศัพท์ติดต่อ
   - LINE ID
   - ที่อยู่จัดส่งสินค้าเริ่มต้น (ดึงข้อมูลอัตโนมัติ ไม่ต้องพิมพ์ซ้ำตอนสั่งซื้อ)
5. **ชำระเงิน & แนบสลิป (Checkout & Slip Upload)**:
   - แสดง QR Code พร้อมเพย์ และข้อมูลบัญชีธนาคารของแม่ค้า
   - ช่องใส่โค้ดส่วนลดโปรโมชั่น (เช่น `JP50`)
   - คำนวณค่าจัดส่งและส่งฟรีเมื่อซื้อครบยอด
   - แนบรูปสลิปหลักฐานการโอนเงิน พร้อมแสดงรูปตัวอย่าง
6. **ติดตามสถานะคำสั่งซื้อ (Order History & Tracking)**:
   - ตรวจสอบสถานะคำสั่งซื้อแบบ Live Timeline (รอตรวจสลิป ➔ ชำระแล้ว ➔ แม่ค้าซื้อของแล้วที่ญี่ปุ่น ➔ จัดส่งพัสดุแล้ว พร้อมเลข Tracking)

---

### 👩‍💼 ฝั่งแม่ค้า (Merchant / Admin Dashboard)
1. **ระบบความปลอดภัย / ล็อกอินแม่ค้า**: เข้าใช้งานผ่าน Username / Password เฉพาะของแม่ค้า
2. **จัดการคำสั่งซื้อ & ตรวจสลิป (Orders & Slips)**:
   - แสดงรายการสั่งซื้อเรียงตามวันเวลา พร้อมข้อมูลลูกค้าครบถ้วน
   - ดูรูปสลิปโอนเงินความละเอียดสูง (Full Modal Preview)
   - ปุ่มอนุมัติสลิป / ปรับสถานะคำสั่งซื้อ
   - บันทึกเลขพัสดุจัดส่ง (Tracking Number)
3. **จัดการสินค้า & หมวดหมู่ (Products & Categories)**:
   - เพิ่ม/แก้ไข/ลบสินค้า, อัปโหลดรูปภาพสินค้า, ตั้งราคาปกติและราคาโปรโมชั่น, ใส่ป้าย Tag
   - เพิ่มหมวดหมู่สินค้าใหม่พร้อมเลือก Emoji ไอคอน
4. **กำหนดรอบบินกลับไทย (Flight Rounds)**:
   - กำหนดชื่อรอบบิน, วันปิดรับ, วันบินกลับไทย, วันเริ่มส่งพัสดุ, สถานะเปิด/ปิดรับ
5. **โปรโมชั่น & คูปอง (Promotions & Coupons)**:
   - สร้างแบนเนอร์โปรโมชั่นหน้าแรก, กำหนดโค้ดส่วนลด และกำหนดยอดซื้อขั้นต่ำ
6. **ตั้งค่า QR ชำระเงิน & ค่าจัดส่ง (Payment Settings)**:
   - อัปโหลดรูป QR Code พร้อมเพย์, เลขบัญชีธนาคาร, ค่าจัดส่ง และยอดส่งฟรี
7. **✨ สรุปรายการของที่ต้องไปซื้อที่ญี่ปุ่น (Japan Buying Checklist)**:
   - ระบบรวมยอดจำนวนชิ้นของสินค้าแต่ละรายการให้อัตโนมัติ พร้อมรายชื่อลูกค้าที่สั่ง
   - มีกล่องติ๊กเช็คลิสต์ (Checkbox) ให้แม่ค้าเปิดดูและติ๊กขณะเดินซื้อของในญี่ปุ่นได้ทันที
   - ปุ่มสั่งพิมพ์ใบรายการสินค้า (Print Checklist)

## 🚀 วิธีการรันระบบ (How to Run)

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์เดียวรันได้เลย (ง่ายที่สุด)
- ดับเบิ้ลคลิกที่ไฟล์ **`start-server.bat`** บนโฟลเดอร์นี้ ระบบจะเปิดรันเซิร์ฟเวอร์ให้อัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / PowerShell
```bash
npm run dev
```
แล้วเปิดเบราว์เซอร์ไปที่: **`http://localhost:3000`**
